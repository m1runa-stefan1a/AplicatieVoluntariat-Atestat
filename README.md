# Platformă de Voluntariat

Atestat la informatică - o aplicație web care conectează voluntarii cu organizațiile.

## 👥 Funcționalități
* **Organizatori:** Pot să-și creeze un profil de administrator și să publice evenimente noi (cu imagini, descriere, cerințe, dată, oră, județ și link de înscriere).
* **Voluntari / Utilizatori:** Pot naviga pe site, pot căuta activități în funcție de județ și se pot înscrie la evenimente.

## 🛠️ Ce am utilizat
* **Frontend:** HTML, CSS
* **Backend:** PHP
* **Bază de date:** MySQL (prin MySQLi)
* **Funcționalități:** JavaScript

## 🚀 Cum poate fi rulat
1. Puneți fișierele într-un server local (cum ar fi XAMPP în folderul `htdocs`).
2. Importați baza de date `voluntariat` în phpMyAdmin.
3. Accesați proiectul din browser folosind `http://localhost/...`.
